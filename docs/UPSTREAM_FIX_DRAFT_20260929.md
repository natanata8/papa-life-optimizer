## ① 目的｜何を実現するか

→ 仕事・育児・家事・自分時間を無理なく回し、気持ちよく一緒に暮らせる家庭を増やす

・「負担」の偏りによる我慢や不満を減らす  
・お互いに休む時間や自分時間を持てる  
・夫婦のすれ違いや摩擦を減らす  
・子どもに余裕を持って向き合える  
・家庭全体に余裕がある状態をつくる

## ② Customer｜誰のためか

→ プレパパ〜未就学児の子どもがいる20〜40代の父親

・仕事をしながら、家事・育児にも参加している  
・仕事で疲れている中でも育児をしており、自分では「かなりやっている」と感じている  
・それでも妻から不満を言われたり、家庭で摩擦が起きる  
・何をすれば家庭が楽になるのか分かっていない  
・飲み会、趣味、休息など自分時間も確保したいが、「そんな時間があるなら子どもの面倒を見て」と言われることがある  
・家庭も大事にしたいが、自分だけが我慢し続ける状態にはしたくない

## ③ Problem｜どんな課題があるか

→ 家庭の負担や状況が見えにくく、「今、自分が何をすればいいか」が分からない

・「自分はこれだけやっている」の認識が、夫婦間でずれる  
・妻がなぜ不満なのか分からない  
・仕事で疲れているので、家庭全体まで考えきれていない  
・家事・育児の見えない作業や負担量を把握できていない  
・飲み会、残業、趣味に行くことで、誰にどんな負担が増えるか分からない  
・ルーティン作業(ゴミ捨て・風呂掃除・お風呂に入れる)などはやるが、前後の負担などを把握できていない  
・問題が起きてから対応するため、いつも後手になる  
・その結果、我慢や不満が溜まり、夫婦の摩擦が増える

## ④ Value｜何を提供するか

→ 家庭の負担を見えるようにし、その家庭に合った「今やること」「先回りしてやること」「問題が起きた時の対応」を、寄り添い・共感しながら具体的に提案する

・家事・育児を、作業だけでなく前後の準備・片付け・判断まで含めて整理する  
・誰にどんな負担がかかっているかを見えるようにする  
・父親本人の仕事・疲労・予定も含めて、共感しながら一緒に考える  
・今、何を優先してやれば家庭の負担が減るかを具体的に出す  
・飲み会、残業、趣味などの予定で増える負担を事前に整理する  
・問題が起きる前に、準備・役割調整・予定変更を先回りして提案し、負担が増える相手にも前向きに伝えられる形にする  
・問題が起きた時は、状況を整理し、今できる現実的な対応を提案する  
・実行結果を記録・パーソナライズし、その家庭でうまくいった方法を次回に反映する

## ⑤ 強み・差別化｜なぜPAPA CODEなのか

→ 家事・育児の負担を増やすのではなく、家庭を回しながら「自分時間・夫婦時間・家族時間」を作ることまで支援する

・プレパパ〜5歳児、さらに2児育児まで、実際に家庭を回しながら自分時間・夫婦時間・家族時間を作っている生の声・実践ノウハウを持つ  
・「もっと育児をしよう」「もっと家事をしよう」で終わらず、今ある負担を可視化・整理して減らす  
・育児や家事をしながらでも、飲み会・趣味・休息・自己投資など「お互いが気持ち良く、好きなことをする」方法を一緒に考える  
・自分時間だけでなく、夫婦時間・家族時間まで含めて提案する  
・家族時間の提案も、単なるおでかけスポット紹介ではなく、パパがそのまま家族に提案できるところまで具体化する  
・家族構成、子どもの年齢、仕事、家事・育児分担、生活リズムを家庭ごとに記憶する  
・過去の相談、実行したこと、うまくいったこと、うまくいかなかったことを次回に反映する  
・家事・育児を、作業名だけでなく前後工程・所要時間・負担量・難易度まで細かく見る  
・父親本人の疲労や予定も含めて判断する  
・問題が起きてから答えるだけでなく、予定や負担を見て先回りして提案する

## ⑥ Solution / Method｜どうやって実現するか

→ AIチャットを中心に、家庭情報・負担データ・予定・過去ログを組み合わせて、その家庭に合った行動・予定・過ごし方を提案する

・**AIチャット**  
　今困っていること、妻とのすれ違い、疲れ、自分がやりたいことなどから相談できる  
　→ 状況を整理し、「今やること」「問題が起きた時の対応」を具体的に提案する

・**家庭プロフィール / パーソナライズ**  
　家族構成、子どもの年齢、仕事、帰宅時間、家事・育児分担、生活リズム、疲労などを記録する  
　→ 同じ相談でも家庭ごとに回答を変える

・**家事・育児の負担データ**  
　家事・育児を、作業名だけでなく前後工程・所要時間・負担量・難易度まで細分化する  
　例：ゴミ出し  
　→ 家中のゴミを集める  
　→ ゴミ袋をまとめる  
　→ ゴミを捨てに行く  
　→ 新しいゴミ袋を設置する

・**カレンダー / 1日のタスク提案**  
　その家庭の予定に合わせて、1日の家事・育児を具体的な時間とタスクに落とす  
　例：7:30〜 ゴミ出し  
　→ 家中のゴミを集める  
　→ ゴミ袋をまとめて捨てる  
　→ ゴミ箱に新しい袋を設置する  
　父親・妻の予定や負担を見ながら、その日に合った内容にパーソナライズする

・**やりたいことからの提案**  
　「飲みに行きたい」「ゴルフに行きたい」「今日は休みたい」「ゲームしたい」などを選択する  
　→ その行動で誰の負担が増えるかを可視化する  
　→ 事前に何をしておけばよいか提案する  
　→ パートナーにどう伝えるかまで提案する

・**先回り / リマインダー**  
　予定・家庭負荷・過去ログから、負担が増えそうなタイミングを事前に検知する  
　→ 「明日は帰宅が遅いので、今日のうちに○○をしておく」  
　→ 「週末の予定前に○○を済ませる」  
　など、問題が起きる前に知らせる

・**ダッシュボード / 負担の可視化**  
　今月の家事・育児・予定による負担を見えるようにする  
　→ 誰に負担が偏っているか  
　→ どの作業の負担が大きいか  
　→ 自分時間・夫婦時間・家族時間が取れているか  
　を確認できる

・**家庭の余裕の可視化**  
　負担だけでなく、自分時間・夫婦時間・家族時間・休息・予定の詰まり具合を見る  
　→ 「今この家庭に余裕があるか」を確認できる

・**夫婦の話し合い支援**  
　負担や予定の可視化をもとに、何を話すか・いつ話すかを提案する  
　→ 感情的になる前に、必要なことを整理して話せる状態を作る

・**パートナーへの伝え方支援**  
　飲み会、残業、趣味、休息などの希望を、そのまま伝えるのではなく  
　→ 事前準備  
　→ 相手に増える負担  
　→ 代替案  
　→ いつ埋め合わせるか  
　まで含めて、前向きに伝えられる形にする

・**自分時間・夫婦時間・家族時間の提案**  
　家事・育児だけでなく、飲み会、趣味、休息、自己投資、夫婦時間、家族時間まで含めて予定を考える

・**おでかけ提案**  
　パパがそのまま家族に提案できる状態まで整理する  
　→ 子どもの年齢  
　→ 移動時間  
　→ 駐車場  
　→ トイレ / おむつ替え  
　→ 食事 / 子ども向けメニュー  
　→ 昼寝  
　→ 料金 / 予約  
　→ 持ち物  
　→ 帰宅時間  
　→ 帰宅後の家庭負担  
　地方インフルエンサーなどのローカル情報も活用する

・**実行後フィードバック**  
　提案したことを実行したか、どうだったか、負担が減ったかを記録する  
　→ 相手の反応  
　→ 本人の負担  
　→ 家庭の雰囲気  
　→ 次回も使いたいか  
　を確認する

・**Household Memory**  
　相談したこと、AIが提案したこと、実際にやったこと、その結果を記録する  
　→ 「この家庭では何をすると上手くいくか」を蓄積する  
　→ 使うほど提案をパーソナライズする

・**PAPA CODEの判断原則**  
　父親を責めない  
　妻を悪者にしない  
　本人の疲労や余裕も考える  
　家庭全体を見る  
　共感だけで終わらず、実際の行動まで提案する
