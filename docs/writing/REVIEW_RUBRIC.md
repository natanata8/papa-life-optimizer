# Writing Review Rubric

各項目0〜2点。10点未満、または非判断・非推測が0点なら利用者向けに出さない。

| 項目 | 0 | 1 | 2 |
|---|---|---|---|
| 非判断・非推測 | 人格評価や感情診断 | 含意が残る | 事実と入力だけに基づく |
| 具体性 | 抽象的な善意 | 行動はあるが条件不明 | 時間、担当、作業、理由が明確 |
| 予定の尊重 | 中止・我慢へ誘導 | 許可する口調 | 実行を前提に負荷を整える |
| 家庭の余裕 | 父親だけ最適化 | 一部負荷を扱う | 準備と回復まで見える |
| 実行可能性 | 多すぎる提案 | 優先順位が弱い | 効果の高い最小行動に絞る |
| 声 | 説教または軽薄 | おおむね中立 | 責めず、止めず、先回りする |

Vale通過は最低条件。AI detectorは採点しない。
