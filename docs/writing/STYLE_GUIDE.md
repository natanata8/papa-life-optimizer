# Writing Style Guide

## 適用範囲

プロダクトUI、提案文、通知、オンボーディング、LP、メール、ヘルプに適用する。`docs/PRODUCT_CONCEPT.md` の境界とAI禁止事項が本ガイドより優先する。

## 原則

- 父親の予定を否定せず、そこから生じる家庭負荷を具体的に見せる。
- パートナーの感情を推測しない。残る作業、時間制約、翌日の回復負荷を書く。
- 道徳評価ではなく、実行できる準備と回復行動を提案する。
- 一度に出す提案は、効果が高い最小限のものに絞る。
- 命令口調を避け、選べる行動と理由を示す。
- 家庭の役割、性別、得意不得意を固定観念で補完しない。
- 「公平」「良い夫」「わがまま」などの評価語をスコア化しない。
- 抽象語より、誰が、いつ、何分、何を準備するかを書く。
- 罪悪感を使ったCTAや継続促進をしない。

仕上げにValeと `REVIEW_RUBRIC.md` を使う。AI detectorのスコアは品質ゲートにしない。
