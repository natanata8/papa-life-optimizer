# MARKET_RESEARCH

状態: 二次調査の草案。競合比較は公開情報ベース。
参入判断やポジショニングの確定は `HUMAN_REQUIRED`。

## 市場の見方

広い市場は「家族の予定・家事・育児の調整」。
このプロダクトが取りに行く狭い市場は「父親の自分時間を、家庭オペレーションとして実行すること」。

広い市場には ind がある。狭い市場は、2026-09-19 時点の公開情報では空白に近い。

## 隣接プロダクト

| プロダクト | 主価値 | このプロダクトとの違い |
| --- | --- | --- |
| TimeTree | 家族の予定共有、予定ごとのチャット | 空き時間は見える。家庭を止めながら休む手順は持たない。 |
| Google カレンダー / LINE | 予定共有と連絡 | 既存習慣。自分時間の型と復帰手順は無い。 |
| ペアワーク | 家事の可視化、時給換算 | 分担の公平は見える。娯楽・回復の実行は扱わない。 |
| Koabit | 家事タスク、ポイント、家族カレンダー | ゲーム化が主。自分時間の許可設計ではない。 |
| ぴよログ等の育児記録 | 睡眠・ミルク等の記録 | 子どものログが主。父親の休みは対象外。 |
| baby-handoff 等の引き継ぎ | 交代時の状況共有 | 近い。ただし育児ログと引き継ぎが主で、自分時間シナリオは持たない。 |

## 空白

父親が休みたい理由は具体的（飲み、ゲーム、ゴロゴロ、朝寝坊）なのに、既存ツールの単位は「予定」か「家事」である。
空白は次の 3 点。

1. やりたいことから逆算して、家庭側の穴を先に埋める。
2. パートナー向けに、突然ではなく事前の依頼として渡せる。
3. 中断と復帰までを、1 シナリオとして持つ。

## 参入条件

勝てると言える条件は、まだ検証されていない。

- カレンダーを置き換えなくてよい。既存の LINE / TimeTree の前段でよい。
- 最初から全家族向けにしない。4 シナリオの完走に集中する。
- 「最適化」より「今夜使える手順」で勝つ。

負け筋:

- 家事アプリの二番煎じになる。
- 父親の娯楽応援メディアになる。
- 入力項目が多く、LINE に負ける。
